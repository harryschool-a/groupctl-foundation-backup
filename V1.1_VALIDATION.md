# v1.1 Validation Notes

The test suite exercises the live provider protocol using a local fake HTTP endpoint. This validates HTTP request/response handling, structured response parsing, task ownership, event attribution, code-proposal artifact storage, patch digest checks, explicit human approval, branch protection, and patch application. It does not claim that any external hosted model or local model server was called during package validation.

A live provider must be available on the user's computer for a real inference run. The runtime accepts OpenAI-compatible Chat Completions endpoints.
